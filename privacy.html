プライバシーポリシー

このサイトについて

BoopaDB（以下「当サイト」）は、BOOTHで販売されているVRChat関連商品の価格履歴を閲覧できる非公式のデータベースサイトです。当サイトは静的なWebページのみで構成されており、アカウント登録機能はありません。当サイトの運営者が、訪問者の個人情報を収集・保存することはありません。

ブラウザ内に保存される情報（localStorage）

当サイトは、利便性のために次の情報を訪問者のブラウザの localStorage にのみ保存します。これらの情報が当サイトや第三者のサーバーへ送信されることはありません。

  • 最近見た商品の履歴（最大100件）
  • ブックマークした商品

これらの情報は、ブラウザの設定から当サイトのサイトデータを削除することでいつでも消去できます。当サイトは広告配信やアクセス解析のための Cookie を使用していません。

アクセス数・インストール数・現在の同時アクセス数の把握のため、運営者のサーバーへ匿名の集計リクエストを送信しています。送信・保存されるのはランダムな端末識別子と集計値のみで、IPアドレスや閲覧したページのURL、個人を特定できる情報は保存されません。

また、商品ページの「おすすめできる」ボタンを押した場合、その投票が運営者のサーバーに保存されます。保存されるのはランダムな端末識別子と商品IDのみで、二重投票の防止と投票の取り消しのためにのみ使われます。個人を特定できる情報と結び付けることはありません。

外部サービスへの接続

商品画像は BOOTH の画像サーバー（pximg）から直接読み込まれます。その際、訪問者のブラウザと BOOTH のサーバーとの間で通信が発生し、IPアドレス等の情報の取り扱いには BOOTH／pixiv株式会社のプライバシーポリシーが適用されます。また、当サイトのホスティングには GitHub Pages を利用しており、アクセスに伴う情報の取り扱いには GitHub のプライバシーステートメントが適用されます。

掲載データについて

当サイトに掲載される価格・商品情報は、公開されている情報を収集したものです。商品画像や商品名の権利は各権利者に帰属します。ショップ運営者の方で、掲載の停止や修正をご希望の場合は、GitHub リポジトリの Issue よりご連絡ください。確認のうえ対応します。
