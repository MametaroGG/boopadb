# BoothDB for VRChat

BOOTH（VRChat向けデジタルアイテム）の価格推移データベース。

- サイト: https://mametarogg.github.io/boothdb/
- 価格データ: [booth-vrc-price-tracker](https://github.com/MametaroGG/booth-vrc-price-tracker) が収集した公開データを利用

現在はプロトタイプ版（サンプルデータで動作中）です。全件データへの接続を順次進めています。

> BoothDB は非公式の個人プロジェクトであり、BOOTH および pixiv株式会社とは関係ありません。BOOTH は pixiv株式会社の商標です。
